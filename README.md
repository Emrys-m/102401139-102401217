# 校园失物招领平台

> 2026 秋软件工程结对作业 · 第二次之程序实现
> 基于纯前端 HTML / CSS / JavaScript 实现，无需任何后端，双击 `index.html` 即可运行。

---

## 一、功能概览

| 模块          | 说明                                                            |
| ------------- | --------------------------------------------------------------- |
| 🏠 首页浏览   | 卡片式展示寻物 / 招领信息，按类型 tab 切换                      |
| 🔍 关键词搜索 | 按物品名称、地点、描述搜索，不区分大小写                        |
| ➕ 发布信息   | 选择寻物 / 招领，填写物品名称、图标、描述、地点、时间、联系方式 |
| 📄 详情查看   | 顶部渐变色块大图，完整信息卡片，一键复制联系方式                |
| ✅ 状态维护   | 发布者可将自己的信息标记为「已找到 / 已归还」，也可重新打开     |
| 👤 我的发布   | 蓝色个人头部 + 统计卡片（已发布 / 进行中 / 已解决）             |
| 💾 本地持久化 | localStorage 存储，刷新不丢；首次打开预置 5 条示例数据          |

## 二、目录结构

```
lost-and-found/
├── index.html          # 主页面（单页应用，含所有 screen 视图）
├── test.html           # 单元测试页（双击直接看测试报告）
├── README.md           # 本文件
├── css/
│   └── style.css       # 全部样式（从原型抽取，移动端优先）
└── js/
    ├── data.js         # 数据层：localStorage 读写 + 纯函数（校验、搜索、筛选、状态更新）
    ├── app.js          # UI 交互：路由、渲染、表单、搜索、详情、状态更新
    └── test.js         # 19 个单元测试用例
```

**设计思路**：UI 完全延续第一次作业的高保真原型（蓝色主调 #3B82F6、左图右文卡片、底部中间凸起 + 号按钮、我的页统计卡片），把静态演示数据换成 localStorage 真数据。`data.js` 尽量写纯函数，不依赖 DOM，便于单元测试。

## 三、使用说明（给测试同学）

### 环境要求

- **谷歌 Chrome 浏览器**（任意较新版本，无需联网，无需安装任何环境）。

### 运行步骤

1. 下载本项目全部文件，保持目录结构不变。
2. 用 Chrome 直接打开 `index.html`：
   - 方式一：文件管理器双击 `index.html`；
   - 方式二：Chrome 地址栏输入 `file:///你的路径/lost-and-found/index.html`。
3. 首次打开自动预置 5 条示例数据。
4. 点底部中间 **+ 号**发布新信息；点顶部搜索框搜索；点任意卡片看详情；在「我的」页管理自己发布的信息并标记完成。

### 运行单元测试

- 用 Chrome 打开 `test.html`，自动执行所有用例并显示通过 / 失败结果。

## 四、附加特点

1. **一键复制联系方式**：详情页点「复制」按钮直接复制到剪贴板。
2. **热门搜索词**：搜索页提供校园卡 / 雨伞 / 耳机 / 钥匙等常用词一键搜索。
3. **物品图标选择**：发布时可从 12 个 emoji 中选一个作为物品图标，卡片和详情页都会显示。
4. **状态可视化**：已解决的卡片自动变灰，状态 pill 显示「寻物中 / 待认领 / 已解决」。
5. **数据本地持久化**：localStorage 存数据，刷新不丢。
6. **响应式布局**：手机全屏、桌面端居中显示为手机宽度容器。

1. **搜索关键词高亮**：搜索结果中匹配的关键词会显示黄色背景，方便快速定位。
